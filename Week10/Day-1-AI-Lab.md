# Python Fundamentals – AI-Assisted Practical Lab Manual

## 1. Learning objectives
After completing this lab manual, participants should be able to:
1. Understand **Python** syntax and language features.
2. Work with **variables** and different data types.
3. Perform operations using Python operators.
4. Implement conditional statements and loops.
5. Understand and implement **OOP concepts**.
6. Use AI prompts to generate and explain Python programs.
7. Debug **Python code** using AI assistance.
8. Execute and validate AI-generated programs.

## 2. Instructions for participants
Follow these instructions for every lab exercise:
1. Copy the provided prompt into an AI assistant.
2. Read the explanation generated by AI.
3. Ask AI to generate the requested Python program.
4. Copy the program into your Python editor.
5. Execute the program.
6. Compare the actual output with the expected output.
7. Modify the program as instructed.
8. Record your observations.

**Important**: Do not simply copy AI-generated code. You must understand every statement and be able to explain the program.
