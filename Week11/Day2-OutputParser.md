# 1. What are Output Parsers in LangChain?
An Output Parser in LangChain is a component that converts the raw response generated by a Large Language Model (LLM) into a structured format that an application can easily understand and process.

By default, an LLM generally returns its response as text. However, real-world applications often require structured data such as:
- Python strings
- Lists
- Dictionaries (JSON)
- Numbers
- Structured objects
- Pydantic models
Output Parsers help transform the LLM's response into the required format.

**In simple words:**

An LLM generates the response, and an Output Parser converts that response into a usable format.

# 2. Why do we need Output Parsers?
Consider an AI-powered employee policy assistant.

An employee asks:

"What are the three main benefits offered by the company?"

The LLM might generate the following response:
```
The company offers three main benefits:

1. Health Insurance
2. Paid Leave
3. Retirement Benefits
```

This response is readable for humans, but suppose the application needs to display the benefits in a dropdown list or use them in another Python function.

# 4. Common Output Parsers in LangChain

# Types of Output Parsers in LangChain

LangChain provides different output parsers depending on the expected response format.

| Output Parser | Purpose | Return Type |
|---|---|---|
| `StrOutputParser` | Returns the model response as plain text | `str` |
| `JsonOutputParser` | Converts the response into JSON-compatible data | `dict` / `list` |
| `CommaSeparatedListOutputParser` | Converts comma-separated text into a list | `list` |
| `PydanticOutputParser` | Converts the response into a validated Pydantic model | Pydantic object |
| `XMLOutputParser` | Parses XML-formatted responses | Nested dictionary |


## 1. StrOutputParser
StrOutputParser converts the response generated by a chat model into a plain Python string.

It is useful when we want to extract the text content from the model response.
```
from dotenv import load_dotenv

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# Load environment variables
load_dotenv()

# Create a Chat Model
model = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)

# Create a Prompt Template
prompt = ChatPromptTemplate.from_template(
    "Explain {topic} in simple words."
)

# Create an Output Parser
parser = StrOutputParser()

# Create a Chain using LCEL
chain = prompt | model | parser

# Invoke the chain
result = chain.invoke({
    "topic": "LangChain"
})

# Display the result
print(result)

# Check the Python data type
print(type(result))
```
## 2. JsonOutputParser
### What is JsonOutputParser?
JsonOutputParser converts an LLM response formatted as JSON into a Python dictionary or list.

JSON is particularly useful when integrating AI applications with REST APIs, databases and other applications.

Business scenario:

An employee onboarding application needs employee details in a structured format.

## 3.CommaSeparatedListOutputParser
### What is CommaSeparatedListOutputParser?
This parser converts a comma-separated text response from an LLM into a Python list.

Business scenario:
```
from dotenv import load_dotenv

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import (
    CommaSeparatedListOutputParser
)

# Load environment variables
load_dotenv()

# Create a Chat Model
model = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)

# Create the Output Parser
parser = CommaSeparatedListOutputParser()

# Get formatting instructions from the parser
format_instructions = parser.get_format_instructions()

# Create a Prompt Template
prompt = ChatPromptTemplate.from_template(
    """
    List three employee benefits.

    {format_instructions}
    """
)

# Create a Chain
chain = prompt | model | parser

# Invoke the chain
result = chain.invoke({
    "format_instructions": format_instructions
})

# Display the result
print(result)

# Check the data type
print(type(result))
```

An HR application needs to retrieve employee benefits as a list.
## 4.PydanticOutputParser
### What is PydanticOutputParser?
PydanticOutputParser converts the LLM response into a Python object defined using a Pydantic model.

It is useful when we need:
- Structured data
- Data type validation
- Mandatory fields
- Data validation rules
- Consistent output formats
**Business scenario:**

An employee recruitment application extracts candidate information from resumes.

We want the LLM to return:
- Candidate name
- Email address
- Experience
- Technical skills
We can define the expected structure using Pydantic.

## 5.XMLOutputParser
### What is XMLOutputParser?
XMLOutputParser converts an XML-formatted LLM response into a Python dictionary.

XML is useful when working with applications that exchange information using XML structures.

Business scenario:

An employee management application needs employee information in XML format.
```

from dotenv import load_dotenv

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import XMLOutputParser

load_dotenv()

# 1. Create Chat Model
model = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)

# 2. Create XML Output Parser
parser = XMLOutputParser()

# 3. Get XML formatting instructions
format_instructions = parser.get_format_instructions()

# 4. Create Prompt Template
prompt = ChatPromptTemplate.from_template(
    """
    Generate employee details in XML format.

    Employee Name: Rahul
    Department: IT
    Experience: 5 years

    {format_instructions}
    """
)

# 5. Generate XML response from LLM
response = (prompt | model).invoke({
    "format_instructions": format_instructions
})

# 6. Display Original XML Response
print("---------- XML OUTPUT ----------")
print(response.content)

# 7. Parse XML into Python Dictionary
result = parser.invoke(response)

# 8. Display Dictionary Output
print("\n---------- DICTIONARY OUTPUT ----------")
print(result)

# 9. Check Data Type
print("\nData Type:", type(result))

```
